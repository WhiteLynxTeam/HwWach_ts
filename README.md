# HwWach

HwWach — система мониторинга оборудования с привязкой техники к пользователям и контролем её использования.

## Статус проекта

- Проект в активной разработке.
- Реализована базовая авторизация и управление пользователями.

## Технологии

- Node.js (актуальная LTS)
- NestJS (TypeScript)
- TypeORM (для работы с PostgreSQL)
- JWT (JSON Web Tokens для аутентификации)
- PostgreSQL
- Docker / docker-compose

## Запуск проекта

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка окружения

Скопируйте файл `.env.example` в `.env` и заполните значения переменных (подключение к PostgreSQL и другие параметры).

```bash
cp .env.example .env
```

### 3. Локальный запуск

development
```bash
npm run start:dev
```

production build
```bash
npm run build
npm run start:prod
```

### 4. Запуск через Docker

```bash
docker compose up --build
```

## Структура проекта (кратко)

- `src/` — исходный код приложения
  - `auth/` — модули авторизации и аутентификации
  - `users/` — модули управления пользователями
  - другие модули будут добавляться по мере разработки

## Планы развития

- Управление оборудованием и привязкой к пользователям
- Логирование и аудит операций
- Панель администратора для контроля техники
